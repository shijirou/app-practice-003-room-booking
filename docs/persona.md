# ペルソナ（架空）

> 架空の利用者像。このペルソナをもとに、要件と画面を考えた。

## 基本
- 名前・年代・仕事: 田中架空（35 歳・営業部）
- 使う機器: 職場の PC（ブラウザ）
- IT の得意さ: 基本的な PC 操作はできるが、複雑なシステムは苦手

## アプリを使う場面
- 社内会議のために会議室を押さえる。
- 顧客とのオンライン商談のために、静かな会議室を押さえる。
- 予定が変わったとき、予約の時間を直す、または取り消す。

## 困っていること
1. 空いている会議室を探すのに、Excel を開いて確認する手間がかかる。
2. 予約が他の人と重なっていた、と後で分かることがある。
3. 変更・取り消しは総務部への連絡が必要で、時間がかかる。

## 望んでいること
1. 一目で空き状況が分かる。
2. 日時の入力を間違えにくい（選ぶだけで入力できる）。
3. 自分の予約を、自分で直せる・取り消せる。

## 機能に落とし込む
| 困りごと | 作る機能 |
|---|---|
| 空き状況の確認が面倒 | 「会議室 × 時間」の表で空き状況を見せる |
| 予約の重複 | Java 側のチェック + DB の排他制約で重複を防ぐ |
| 日時の入力間違い | 30 分刻みの選択式。終了が開始より前は受け付けない |
| 変更・取り消しに時間がかかる | 自分の予約の変更・キャンセル |
