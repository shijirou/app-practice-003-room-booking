# 画面デザイン

[要件定義書](requirements.md) の「画面」の詳細。まだ作っていない画面の**設計案**。
ブラウザで見られるモックは [mock/index.html](mock/index.html)（ファイルをブラウザで開く。DB・API なしの見た目確認用。リロードすると元に戻る）。
画面は 1 つだけ。パソコン（幅 1024px 以上）を想定。

## 完成デザイン（文字と線の図）

```
┌──────────────────────────────────────────────────────────────┐
│ 会議室予約                          操作する社員 [田中架空 ▼]      │
├──────────────────────────────────────────────────────────────┤
│ [◀ 前の日]  2026-11-20(金)  [今日]  [次の日 ▶]                    │
│            8:00  9:00  10:00 11:00 12:00 ... 19:00              │
│ 会議室A(4)  │ 空き │ 営業定例(佐藤) │ 空き │ ...                    │
│ 会議室B(6)  │ 空き │ 空き │ 空き │ 商談(田中) ← 自分の予約は青       │
│ 会議室C(10) │ ...                                               │
│ 商談ブース(2)│ ...                                               │
│ （空きのマスを押すと、下のフォームに会議室と開始時刻が入る）           │
├───────────────────────────┬──────────────────────────────────┤
│ 予約する                     │ 自分の予約                          │
│ 会議室 [会議室A ▼]            │ 11/20(金) 10:00〜11:00 会議室B       │
│ 日付   [2026-11-20]          │   営業定例        [変更] [キャンセル]   │
│ 開始   [10:00 ▼]             │ 11/22(日) 14:00〜15:30 商談ブース     │
│ 終了   [11:00 ▼]             │   オンライン商談   [変更] [キャンセル]   │
│ 用件   [            ]        │                                    │
│ [予約する]                   │                                    │
└───────────────────────────┴──────────────────────────────────┘
```
- 上の表の列は 30 分ごと（8:00〜20:00）。予約済みのマスは予約の長さに合わせてつながり、「用件（社員名）」を出す。
- 自分の予約は青、ほかの人の予約はグレー、空きは白。

### 変更中（「変更」を押したあと）
フォームの見出しが「予約を変更する」になり、ボタンが「変更を保存」「やめる」に変わる。現在の内容がフォームに入る。

## 部品と役割
| 部品 | 要件 | 見た目・動き |
|---|---|---|
| 社員の選択 | F1 | 画面右上。選んだ社員が、予約・変更・キャンセルの操作者になる。選び直すと「自分の予約」も切り替わる。ブラウザに前回の選択を覚えておく |
| 日付の切り替え | F2 | 「前の日」「次の日」「今日」と、日付の表示。日付を直接選ぶこともできる |
| 空き状況の表 | F2 | 行が会議室、列が 30 分ごとの時間。空きのマスは押せる（開始時刻がフォームに入る）。過去の時間のマスは押せない |
| 予約フォーム | F3 | 会議室・日付・開始・終了は**選ぶだけ**。開始・終了は 30 分刻みの選択式で、終了の選択肢は開始より後だけ。用件は任意（50 文字まで） |
| エラー表示 | F3・F4 | フォームの上に赤い文字で原因を 1 文で出す（例: 「その時間はすでに予約があります」）。入力した内容は消さない |
| 自分の予約 | F4 | 今から先の自分の予約を、日時の早い順に並べる。なければ「予約はまだありません」 |
| 変更ボタン | F4 | 押すとフォームに内容が入る。「変更を保存」で確定、「やめる」で取り消し |
| キャンセルボタン | F5 | 確認メッセージで OK したときだけ取り消す。変更ボタンから少し離す |

## 予約の流れ（3 ステップ）
1. 空きのマスを押す（会議室・日付・開始が入る）
2. 終了時刻を選ぶ（必要なら用件を書く）
3. 「予約する」を押す

## 配置の考え方
- 一番知りたいのは「いつどこが空いているか」なので、空き状況の表を上に大きく置く。
- 日時は入力させず選ばせる。終了の選択肢を開始より後だけにして、入力間違いが起きない形にする。
- 自分の予約は、表の下の右側にまとめ、予約フォームの隣に置く。
- 画面の幅は最大 1200px。それより広い画面では、中央に寄せる。

|---|---|---|

| 文字 | 濃いグレー | `#1b1f24` |
| 薄い文字 | グレー | `#5f6975` |
| カード・表の背景 | 白 | `#ffffff` |
| 空きのマス | 白（縁はうすいグレー）。カーソルを合わせると薄い青 | `#ffffff` |
| 自分の予約・ボタン | 青 | `#0b5cad` |
| ほかの人の予約 | グレー | `#c9ced6` |
| エラー・キャンセル | 赤 | `#b3261e` |
